### 🔹 Как работает интеграция

1. Пользователь вводит команду `/employees`
2. Бот запрашивает ввод (имя или отдел)
3. Данные считываются из CSV файла с помощью pandas
4. Выполняется поиск по введённой строке
5. Результаты форматируются и отправляются пользователю

import pandas as pd

def search_employee(query):
    df = pd.read_csv('employees.csv')
    result = df[
        df['name'].str.contains(query, case=False) |
        df['department'].str.contains(query, case=False)
    ]
    return result
