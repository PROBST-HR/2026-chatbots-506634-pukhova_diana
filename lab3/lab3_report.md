# 2. Процесс деплоя

## Шаги деплоя
1. Создан Telegram-бот через BotFather
2. Написан код бота на Python (python-telegram-bot v20)
3. Добавлены команды:
   - /add — добавление задач
   - /list — просмотр задач
   - /done — выполнение задач
   - /clear — очистка списка
4. Код загружен в GitHub репозиторий
5. Подключен проект к Railway
6. Добавлена переменная окружения BOT_TOKEN
7. Выполнен автоматический деплой

## Проблемы, с которыми столкнулись
- Ошибка `Updater` (несовместимость старого API)
- Ошибка отсутствия `BOT_TOKEN` в переменных окружения
- Ошибка установки `pandas` на Python 3.13

## Решение проблем
- Переписан бот под `ApplicationBuilder` (python-telegram-bot v20+)
- Удалён `pandas` для упрощения деплоя
- Добавлены переменные окружения в Railway
- Упрощена архитектура хранения задач (в памяти)
