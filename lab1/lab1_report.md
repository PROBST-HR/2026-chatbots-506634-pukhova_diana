# Отчет по лабораторной работе  
## Telegram-бот для управления задачами с напоминаниями

---

## 📌 Описание задачи

В рамках лабораторной работы был разработан Telegram-бот для управления задачами.  
Бот позволяет пользователю:

- Добавлять задачи
- Указывать приоритет (высокий / средний / низкий)
- Настраивать напоминания
- Просматривать список задач
- Удалять задачи

### 🎯 Какую проблему решает бот

Бот помогает пользователю:

- Не забывать о важных задачах
- Упорядочивать дела по приоритету
- Получать своевременные напоминания
- Хранить список задач в удобном формате

### 🤔 Почему выбрана эта задача

- Практическая полезность (ежедневное применение)
- Подходит для изучения Telegram API
- Позволяет реализовать:
  - диалоговые сценарии (ConversationHandler)
  - хранение данных
  - асинхронные задачи (напоминания)

## 🤖 Промпт для LLM

### 🧠 Исходный промпт

Создай Telegram-бота на Python с использованием библиотеки python-telegram-bot.

Функционал бота:
- Пользователь может добавлять задачи
- Бот сохраняет задачи в список
- Бот показывает список задач
- Бот удаляет задачи по номеру

Команды:
- /start — приветствие
- /add — добавить задачу
- /list — показать список задач
- /delete — удалить задачу

Логика:
- После /add бот просит текст
- После /delete бот просит номер
- Данные сохраняются в JSON файл
- У каждого пользователя свой список

Требования:
- Простой код
- С комментариями
- Обработка ошибок

Создай:
1. bot.py
2. requirements.txt
3. README.md
4. .env.example

## ⚠️ Трудности и решения

### ❌ Проблемы

1. Ошибка `InvalidToken`
2. Ошибка `no running event loop`
3. Ошибка `KeyError: 'text'`
4. Бот не запускался
5. Неправильный путь к файлу
6. Ошибки форматирования (IndentationError)

---

### ✅ Решения

- Токен вынесен в `.env`
- Использован `JobQueue` вместо `asyncio.create_task`
- Добавлена безопасная работа с данными (`.get()`)
- Исправлены отступы
- Проверен путь запуска (`cd в папку проекта`)
- Добавлена обработка ошибок
